超级管理员开关

  1. 部署时设置 Base44 服务端密钥 SUPER_ADMIN_USER_ID，填指定超级管理员的真实 User ID，且此账户的内置角色必须为 admin。
  2. 进入 CRM → 经销商管理 →“合伙人平级奖励承担方式”。普通管理员只读；服务端同时检查角色与固定身份。
  3. 选择“总部承担”或“指定上级承担”，填写变更依据。指定模式还需逐一设置合伙人的承担方。
  4. 初始不自动选择。未设置、缺少指定承担方、承担方被停用或降级，均阻止受影响的结算。
  5. 每笔订单保存规则版本、人员关系、承担方和开关版本。切换只影响后续确认完成的订单，不追溯改写已结算账目。

准确性修复

  • 金额以整数分计算，每位收款人各自四舍五入到分；承担方扣款等于这些实际入账金额的总和，避免 0.01 的舍入差。
  • 为三个等级配置真实拿货价；不得回退到零售价。确认订单时核对页面报价，价格变化需刷新确认。
  • 修复取消早期出货单导致后续成本批次重排的问题；每笔订单保存采购单ID、明细序号、数量和单价。
  • 产品类别随采购批次保存，结算页面不能把 GeneCells 改选成全业产品来多发返点。
  • 每个账户的分润与提现共用原子状态更新；失败可重试，收款人和承担方均防重复入账。未完成结算不进入正式账单展示或提现余额。
  • 对账时同时显示正收益和奖励支出；概览、每日业绩和提现使用同一来源快照。
  • 总部开关和指定承担方的变更记录保留操作者、说明及版本，普通管理员直接请求也不能越权。

验证与上线条件

48 项测试包含三等级公式、整数分边界、第四级无奖励、零实收不消耗首单资格、并发首单、负收益、失败恢复、采购价格、批次取消恢复、超级管理员鉴权、两种承担模式及历史快照不变。测试模拟 Base44 的单ID原子 CAS，不替代真实平台集成验证。

上线需同时发布新增函数、实体字段和全部前后端，设置超级管理员身份及商品等级价格，迁移历史积分／采购／批次。历史错误成本、旧版已入账分润不自动追溯更改。切换部署期间应暂停金融写入，并在测试环境验证权限、并发和资金核对。
