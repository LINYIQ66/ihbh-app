# iHBH 经销商转介绍规则

规则确认日期：2026-10-27。适用于合伙人、官方、总代的同级转介绍。
用户已确认原示例第 3 条中的“合伙人 A 得到 B 回款的 3%”应为“合伙人 A 得到 **C** 回款的 3%”。

## 横向同级转介绍

关系链：原介绍人 → A → B → C → D。以下每行均按该成交人的首笔完成销售实收 S$1,000 举例。

| 成交人 | 直接介绍人 5% | 第二级 3% | 第三级 2% | 一次性居间费 8% |
| --- | --- | --- | --- | --- |
| A | 原介绍人 S$50 | 无 | 无 | 原介绍人 S$80 |
| B | A S$50 | 原介绍人 S$30 | 无 | A S$80 |
| C | B S$50 | A S$30 | 原介绍人 S$20 | B S$80 |
| D | C S$50 | B S$30 | A S$20 | C S$80 |

每笔回款只向最近三位同级介绍人支付 5%／3%／2%；D 成交时，原介绍人不再获奖。不会隔三代重新支付给更远的介绍人，也不会同时拿 B 的回款计算 C 的奖励。

8% 只按被介绍经销商首笔有实收的完成销售支付一次，给直接同级介绍人。后续销售不重复支付，零实收不消耗首笔有实收资格。符合条件的毛差、全业返利、渠道分润、三级回款奖励及居间奖励叠加。

## 支付承担方

| 项目 | 承担方 |
| --- | --- |
| 所有等级的 8% 居间费 | **HBH 体验馆** |
| 官方的同级 5%／3%／2% 奖励 | 被介绍、实际成交官方的直属合伙人 |
| 总代的同级 5%／3%／2% 奖励 | 被介绍、实际成交总代的直属官方 |
| 合伙人的同级 5%／3%／2% 奖励 | 按此前确认保留超级管理员开关：总部承担，或指定上级合伙人承担 |

三级奖励承担方记等额支出，金额为各收款人逐项四舍五入到分后的合计。体验馆承担的 8% 不扣经销上级收益，也不受合伙人回款奖励开关影响。

`experience_hall` 是居间费的责任方标记，并不代表系统已向银行发起付款。当前代码不凭空指定某个体验馆账户；实际财务付款仍需核实和处理。

## 纵向不同等级销售

商品毛差 = 本笔销售实际收款 − 已确认采购批次的实际成本。以单瓶价格举例：

| 销售关系 | 实际成本 | 本笔实收 | 商品毛差 |
| --- | --- | --- | --- |
| 合伙人 → 官方 | S$160 | S$300 | S$140 |
| 合伙人 → 总代 | S$160 | S$430 | S$270 |
| 官方 → 总代 | S$300 | S$430 | S$130 |
| 总代 → 消费者 | S$430 | S$530 | S$100 |

表中价格仅用于说明差价；实际结算使用具体商品已核实的采购成本和销售实收，不按展示价强行结算。毛差尚未扣除奖励支出、税费及其他经营成本。

上下级渠道关系与同级介绍关系分别保存。纵向销售不会因为买卖双方有等级关系就自动生成同级介绍奖励；奖励必须有对应的同级介绍链。官方、总代销售所触发的同级回款奖励，由表中规定的直属上级承担。
